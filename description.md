# 🌙 Veil Origins

**A comprehensive, standalone origin system for Minecraft 1.21.1 through 1.21.11**

*Transform your Minecraft experience with unique character origins, abilities, and passives.*

---

## ⚠️ IMPORTANT DISCLAIMER ⚠️

**This mod is a completely SEPARATE and INDEPENDENT project.**

It is **NOT** an official port, fork, or affiliate of the original **Origins** mod by **Apace100**.

Veil Origins is built from the ground up with its own codebase, unique abilities, and custom systems for NeoForge.

*Please do not report issues from this mod to the original Origins developers.*

---

## ✨ Features

Veil Origins is a massive expansion to the origins genre, introducing **21 unique playable origins**, each with custom abilities, visual effects, and playstyles.

*   ✅ **21 Unique Origins** - Ranging from the blood-thirsty Vampire to the reality-bending Riftwalker.
*   ✅ **Active Ability System** - Use **[R]** and **[V]** to trigger powerful active skills.
*   ✅ **Custom HUD & UI** - Beautiful animated HUD with a built-in **Config Screen (Press 'H')**.
*   ✅ **Vampire Blood System** - Complete overhaul of hunger for Vampires with blood bars and bottles.
*   ✅ **Radial Menu** - Intuitive ability selection.
*   ✅ **Multiplayer Ready** - Fully synchronized for servers.

## 🛠️ New in v1.0.4

### 🩸 Vampire Blood Overhaul
*   **New Blood Bar**: Replacing the hunger bar entirely for Vampires.
*   **Bottles**: Craft and fill **Blood Bottles** to store sustenance.
*   **Mechanics**: Drain enemies to refuel. Running empty causes starvation!

### ⚙️ HUD Configuration & Font Engine
*   **Press 'H'** to open the new **HUD Editor**.
*   Customize position, visibility, and opacity of all HUD elements.
*   New **Unicode Font Handler** for crisp, beautiful text.

## 💻 Commands & Controls

| Input | Action |
| :--- | :--- |
| **`R`** | Primary Ability |
| **`V`** | Secondary Ability |
| **`O`** | View Origin Info |
| **`H`** | Open HUD Configuration |
| `/veilorigins list` | (Admin) List origins |
| `/veilorigins set` | (Admin) set player origin |
